# 07 — Frontend Integration

> [Mastery Guide](../README.md) › Frontend Integration

The Angular stack: components and templates, RxJS for reactive data flow, NgRx for predictable state at scale, and Service Worker / PWA for offline-capable web apps. Treat this as a parallel track that can run alongside backend phases — start once you've finished Phase 3 (ASP.NET Core fundamentals).

## Recommended reading order within this chapter

1. **Angular Fundamentals** — components, dependency injection, routing, forms.
2. **RxJS** before NgRx — Observables are NgRx's currency. Study operators and the `async` pipe pattern.
3. **NgRx** once RxJS clicks — actions, reducers, effects, selectors.
4. **Service Worker & PWA** for offline / installability — usually last, often optional.
5. **Angular Testing** alongside everything else — TestBed, HttpTestingController, NgRx testing, Playwright for E2E. Ship with tests, not after.
6. **Angular SSR & Hydration** for content-heavy or SEO-critical apps — full and incremental hydration, TransferState, deployment models.
